# Demo Dataset

The example dataset required to run and test the ImageJ/Fiji kymograph analysis macros is hosted separately from this GitHub repository because of its large file size (~1.4 GB).

## Dataset

The demo dataset is available at:

https://drive.google.com/file/d/1pTFO4lg9WsplZXRgUbDZMYTSp3b9dWq3/

The dataset contains the input time-lapse image and associated ROI files required to test the kymograph analysis workflow.

## Usage

Download the demo dataset and follow the instructions in the main repository `README.md` to run:

- `Lab_Frame_and_Posterior_Aligned_Kymograph.ijm`
- `Anterior_and_Determination_Front_Aligned_Kymograph.ijm`

The dataset is provided to demonstrate the operation of the macros on representative experimental data.
