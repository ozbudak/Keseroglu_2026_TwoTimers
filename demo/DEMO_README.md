# Demo Dataset

This folder contains an example dataset for running and testing the
ImageJ/Fiji kymograph analysis macros.

## Dataset

The demo dataset includes an example maximum-projected YFP time-lapse
image (`example_timelapse.tif`) and associated ROI files required to
test the kymograph analysis workflow.

## Usage

Use the demo dataset and follow the instructions in the main repository
`README.md` to run:

-   `Lab_Frame_and_Posterior_Aligned_Kymograph.ijm`
-   `Anterior_and_Determination_Front_Aligned_Kymograph.ijm`

The dataset is provided to demonstrate the operation of the macros on
representative experimental data.
